Marmalade STT · Arabic RTL audit

Every screen in Arabic on the API 35 emulator, before and after the #69 fixes 2026-10-05
emulator Pixel 6 profile, default font size, light mode

The app is set to Arabic with Android's per-app language (cmd locale set-app-locales … ar) on an English emulator. Compose mirrors layouts on its own (supportsRtl holds), so most screens were already right: rows, chevrons, back arrows, switches, sliders, the meters (they fill from the right), dialogs' button order, the progress bar of the setup guide. The bugs were in text that isn't the app's own translated words, and in the keyboard panel. Long locales (ru, uk, pl, vi, id) are at the bottom.
