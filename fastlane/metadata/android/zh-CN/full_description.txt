<p>Marmalade STT 在你的手机上把语音转成文字。可以把它用作键盘（FUTO Keyboard、HeliBoard、FlorisBoard 等）的语音输入，也可以用于向 Android 请求语音输入的应用。你的声音绝不会离开手机。</p>

<ul>
<li><b>私密：</b>语音在手机上识别。音频绝不会被保存或上传</li>
<li><b>离线：</b>只需下载一次语音引擎，之后无需联网即可使用</li>
<li><b>实时文字：</b>在你说话的同时实时显示文字，大多数引擎都支持</li>
<li><b>知道你何时说完：</b>Smart Turn 是“请说话”弹窗的默认方式，它会等到听起来你已经说完，所以停下来思考时很少会被打断</li>
<li><b>多语言：</b>支持 100 种语言，并自动为你的语言选择最合适的引擎</li>
<li><b>输出整洁：</b>去除语气词，数字写成阿拉伯数字，还有你自己的替换规则和用语音触发的文本片段</li>
<li><b>免费开源：</b>无广告、无账户、无分析</li>
</ul>

<p><b>隐私源于设计</b></p>
<p>无分析、无跟踪、无崩溃报告、无账户，也没有我们自己的服务器。仅在从 GitHub 下载你选择的语音引擎时使用互联网，且每个文件都会用预先固定的 SHA-256 哈希值校验。Android 备份已关闭，因此不会有任何内容被复制到云端。</p>

<p><b>何时停止由你决定</b></p>
<p>在“请说话”弹窗和其他应用中，Marmalade 默认使用 Smart Turn v3 技术来检测你何时说完。无需动手。觉得它太早打断你？可以改为停顿后停止，或者改为设置一个结束词。在键盘上，它会一直聆听直到你点按，也可以同样使用 Smart Turn。</p>

<p><b>整洁的文字</b></p>
<p>可选的文本整理会修正大小写；对于英语，还会去除语气词，把“new line”和“period”变成真正的换行和句点，并把数字写成阿拉伯数字。用于修正引擎听错的名字的替换规则，以及用于插入常打文字的文本片段，适用于任何语言。</p>

<p><b>适用于你的键盘</b></p>
<p>开启“Marmalade 语音输入”后，键盘上的麦克风键会打开一个小小的 Marmalade 面板，把你说的话输入进去。支持 FUTO Keyboard、HeliBoard、FlorisBoard、AnySoftKeyboard、Unexpected Keyboard、AOSP 键盘以及其他带语音键的键盘。</p>

<p><b>适合你手机的引擎</b></p>
<p>设置向导会根据你的语言以及手机的内存和速度推荐一个语音引擎，你也可以下载并试用其他模型。</p>

<p><b>语言</b></p>
<p>快速引擎支持英语、保加利亚语、克罗地亚语、捷克语、丹麦语、荷兰语、爱沙尼亚语、芬兰语、法语、德语、希腊语、匈牙利语、意大利语、拉脱维亚语、立陶宛语、马耳他语、波兰语、葡萄牙语、罗马尼亚语、俄语、斯洛伐克语、斯洛文尼亚语、西班牙语、瑞典语、乌克兰语、日语、印地语、阿拉伯语和越南语。中文和韩语使用比 Whisper 更轻量的 Qwen3-ASR。你也可以在它支持的其他 28 种语言（包括英语）中选用它。其他语言通过 Whisper Large v3 Turbo 识别，延迟更高。</p>

<p><b>开源</b></p>
<p>Marmalade STT 采用 MIT 许可。如果你想支持它，可以在“设置 → 支持”中找到 GitHub Sponsors 的链接；无论是否支持，应用都完全一样。</p>
