# Marmalade STT website

The project website, served by GitHub Pages from this orphan `website` branch
(no shared history with `main`). Plain HTML and CSS in `index.html`, with a
little inline JavaScript for the theme toggle, the hero sample and the
language card. No build step and no third-party requests.

- `assets/audio/hero.*`: the hero sample, a synthetic voice (Kokoro-82M,
  af_heart). The text the hero shows is the app's own output for it.
- `assets/screenshots/`: the store screenshots, black frame cropped, as WebP.
- `assets/fonts/`: Manrope and Momo Trust Display, subset to Latin (OFL-1.1).
- `assets/get-it-on-fdroid.svg`: the official F-Droid badge (CC BY-SA 3.0).
